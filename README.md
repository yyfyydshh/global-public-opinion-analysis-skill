# 全球舆情与品牌口碑分析（八爪鱼）

- 版本：2.8.0
- 入口：[`SKILL.md`](SKILL.md)
- 连接器：DataHub，由客户在 WorkBuddy 使用本人账号授权
- 编排：1 个根 Skill + 9 个内部 Skill

## 主要能力

- 全球公开网页与中文、海外资讯检索。
- 品牌声誉、产品 VOC、竞品口碑和事件舆情分析。
- 候选预览、续采、来源治理和证据门槛。
- 交付 Markdown、Excel 数据包与可选 HTML。
- 提供开工、真实批次、候选预览、清洗和交付物生成进度。

安装目录不含访问凭证；客户交付物不显示连接器账单、余额或额度。
